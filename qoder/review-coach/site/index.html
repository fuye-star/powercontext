复习教练

把散落的笔记交给 seekdb 检索，把做错的题交给 PowerContext 记住。每复习一次，下一次检索和出题就更贴近你的薄弱点。

Qoder 开发 seekdb 全文检索 PowerContext 记忆 Python CLI

要解决的问题

笔记找不回

几十篇 Markdown 笔记散在文件夹里，只记得“在哪篇写过”，复习时靠翻目录，时间都花在找资料上。

错题没人记

同一个知识点反复错，但没有任何工具记得“你在检索这一章正确率只有 0”，下次复习还是从头看。

检索与记忆割裂

普通笔记工具只做检索，普通刷题工具只做记录；两边数据不通，无法做到“按薄弱点优先复习”。

核心功能

命令做什么指定技术的作用
coach init建库建表并导入笔记seekdb 建库、FULLTEXT ... WITH PARSER ngram
coach ask alice "混合检索怎么融合两路结果"检索相关笔记并给出来源seekdb MATCH ... AGAINST 打分排序
coach review alice note-3 --wrong记录一次复习结果PowerContext 写入记忆
coach stats alice查看正确率、薄弱主题、最近查询PowerContext 跨进程读取记忆
coach quiz alice按薄弱主题生成填空题记忆决定出题范围 + seekdb 取题

真实运行效果

以下为本机实际运行输出（seekdb 服务端 v1.4.0.0，PowerContext Python SDK + SQLite）。

$ python -m coach ask alice "混合检索怎么融合两路结果"

$ python -m coach review alice note-3 --wrong
{"user":"alice","note":"note-3","topic":"检索","correct":false,"topic_accuracy":0.0,"weak_topics":["检索"]}

$ python -m coach ask alice "向量检索"

[note-2] 向量索引与 HNSW（向量，score=0.286）

$ python -m coach quiz alice

混合检索同时使用向量相似度和全文关键词匹配。____ 按排名倒数融合两路结果，……
答案：RRF

技术分工

seekdb

笔记表 notes(id,title,topic,source,content)，ngram 全文索引；检索全部由 SQL 完成，返回分数用于排序。

PowerContext

一个 Scope 保存复习记录与最近查询；每次命令都是新进程，仍能读出薄弱主题并影响检索与出题。

Qoder

需求拆解、代码生成、调试与网站发布均在 Qoder 中完成，过程记录见仓库 QODER_LOG.md。
